# Network Configuration Documentation

**SSK Controls:** 06-5, 07-4  
**Owner:** Director of IT & MIS  
**Date:** 2026-04-26  
**Review cycle:** Annual

MCNA's network topology, firewall rule sets, switch configurations, and VLAN assignments are documented and maintained by DIS Computers as part of the managed services agreement. Documentation includes a current network diagram, IP address scheme, VLAN layout, WAN/LAN architecture, and firewall policy summary.

The Director of IT & MIS holds a current copy of the network diagram and firewall policy summary in the IT & MIS SharePoint library. DIS maintains the authoritative configuration backups and change records in their managed service ticketing system.

Network configuration documentation is reviewed jointly by the Director of IT & MIS and DIS when significant changes occur (new site, major infrastructure change, firewall rule set revision) and at minimum annually. Changes to network configuration are change-controlled through DIS's change management process with advance notice to the Director of IT & MIS.
