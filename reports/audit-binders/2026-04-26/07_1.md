## Recommended Actions

| ID | Action | Status | Owner |
|----|--------|--------|-------|
| 07-1-a | Understand all component hardware and related software (including virtual OSes or cloud components) that comprise the wider system; record this information (configuration) in a listing or inventory database, along with version number etc. of each component | not_started | — |
| 07-1-b | Associate Active Ports, Services, and Protocols with an asset inventory/list/database/ledger | not_started | — |
| 07-1-c | Use DHCP logging or IP address management tools to identify assets connected to the system | not_started | — |
| 07-1-d | Establish a baseline secure configuration standard based on the principle of least privilege (PoLP) | not_started | — |
| 07-1-e | Periodically apply system configuration settings automatically using a system settings management tool to prevent unintentional changes to configuration settings | not_started | — |
| 07-1-f | Check if the configuration settings have been changed to unauthorized settings, or verify that no unauthorized service is running | not_started | — |
| 07-1-g | Confirm that system software has not been tampered with by secure boot, TPM, verification of digital signature, etc. | not_started | — |
| 07-1-h | Uninstall or disable unnecessary services, such as unused file sharing services, web application modules, and service features | not_started | — |
| 07-1-i | Periodically confirm that system configuration information is up to date | not_started | — |
