# Secure SketCH Control Check

Use this skill when the user wants a single Secure SketCH control tested and stored as an auditor-friendly report.

## Workflow

1. Run `ssk_run_control_check(control_id, generated_by="Dave Lafferty", notes=None)`.
2. If the payload contains `error_type`, stop and report the exact error.
3. Read `result.json` from `output_dir`.
4. Run:
   `python .agents/skills/ssk-run-control-check/scripts/render_control_check_docx.py <result.json path>`
5. Confirm these artifacts exist in the same run folder:
   - `check.md`
   - `result.json`
   - `<control_id>-<YYYY-MM-DD>.docx`
6. Report status, tools run, finding count, evidence ID, and exact artifact paths.

## Hard Rules

- Do not infer a pass. Use the tool's `status` exactly.
- `manual_required` means there is no automated mapping for this control.
- Do not fabricate evidence, findings, or artifact paths.
- If `result.json` is missing, malformed, or the Word render fails, stop and report it as a failure.
- If the tool mapping looks questionable, include a trust warning in the final response.

# Expected Report Shape

- Title: `Secure SketCH Control Check <control_id>`
- Summary block: title, generated date/time, generated by, status
- Executive summary
- Tools run
- Findings summary
- Detailed findings
- Evidence record
- Artifact locations
- Operator notes (only when supplied)
